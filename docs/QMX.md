# QRP Labs QMX+ Integration

## Status

Der QRP Labs QMX+ ist als vierter Transceiver für den
SHACK-SERVER vorbereitet.

Der QMX+ stellt über USB einen Virtual COM Port für
CAT-Control bereit.

Die Integration implementiert das gemeinsame
`RadioService`-Interface des SHACK-SERVER.
