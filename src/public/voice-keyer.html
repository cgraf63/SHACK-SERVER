Microphone needs HTTPS. The browser only allows recording on a secure page – open SHACK-SERVER as https://… (see the manual, chapter Network), or load an audio file (WAV, MP3, M4A …) that you recorded elsewhere with FILE.
Speak about a hand's width from the microphone. The recording is trimmed (silence at the start and end) and brought to the same level. Set the TX level on the transceiver (USB modulation gain) once so the ALC barely moves. Show the line on the dashboard / in the contest console in Settings › Split & CW; in the contest console F1–F8 play the messages.
